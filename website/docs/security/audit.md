# Security Audit

The Liquid Positions plugin was audited by **Hacken** (report date: March 2026, retest included).

## Audit Scope

The audit covered the following contracts:

- `LPPlugin.sol`
- `LPPluginFactory.sol`
- `LPToken.sol`
- `LPTokenFactory.sol`
- `LPCallback.sol`

## Report

The full audit report is available in the repository:

```
Hacken_E_Storm_SCA_EStorm_Token_Jan2026_retest_P_2026_2020_4_20260311.pdf
```

## Summary

The retest report confirms all findings from the initial audit were addressed prior to publication. No critical or high severity issues were outstanding at the time of the retest.

## Disclaimer

An audit is a point-in-time review and does not guarantee the absence of all vulnerabilities. Always review the current contract source, check for any post-audit changes in the repository's git history, and apply your own risk assessment before integrating or depositing funds.
