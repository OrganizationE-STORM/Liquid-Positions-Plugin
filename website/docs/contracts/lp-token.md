# LPToken

**File:** `contracts/LPToken.sol`
**Inherits:** `ERC20`, `Ownable`

A standard ERC-20 token representing a proportional share of one specific tick-range position. One `LPToken` contract is deployed per `(tickLower, tickUpper)` pair, the first time liquidity is deposited into that range.

Mint and burn are restricted to the contract owner, which is always the `LPPlugin` that deployed it.

## Constructor

```solidity
constructor(string memory name, string memory symbol)
```

Sets the ERC-20 name and symbol, and assigns the deployer (`LPTokenFactory`) as the initial owner. Ownership is immediately transferred to the calling `LPPlugin` after deployment.

## Naming Convention

The name and symbol are generated by `LPPlugin._mintLPTokens()` when the token is first created:

| Field | Format | Example |
|-------|--------|---------|
| Name | `LPToken {sym0}-{sym1} {tickLower}-{tickUpper}` | `LPToken ETH-USDC -60-60` |
| Symbol | `{sym0}-{sym1} {tickLower}-{tickUpper}` | `ETH-USDC -60-60` |

Where `sym0` and `sym1` are the `symbol()` return values of the pool's `token0` and `token1`.

## Functions

### `mint` _(onlyOwner)_

```solidity
function mint(address to, uint256 amount) external onlyOwner
```

Mints `amount` tokens to `to`. Only callable by the owning `LPPlugin`.

---

### `burn` _(onlyOwner)_

```solidity
function burn(address from, uint256 amount) external onlyOwner
```

Burns `amount` tokens from `from`. Only callable by the owning `LPPlugin`.

---

### Standard ERC-20

All standard `IERC20` functions are available: `transfer`, `transferFrom`, `approve`, `balanceOf`, `totalSupply`, `allowance`.

## Decimals

Inherits the OpenZeppelin `ERC20` default of **18 decimals**.

## Token Supply Lifecycle

| Event | Effect on Supply |
|-------|-----------------|
| First deposit into range | Supply goes from 0 → `10^32` |
| Subsequent deposits | Supply increases by `depositValue × totalSupply / positionValue` |
| Withdrawal | Supply decreases by the burned amount |
| Full withdrawal (burn all) | Supply returns to 0; token contract remains deployed |

When the total supply reaches zero the LPToken contract is not destroyed — subsequent deposits will remint starting from `INITIAL_LP_TOKEN_TO_MINT = 10^32` again.
